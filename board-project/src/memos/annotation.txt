@Service = "이 클래스가 비즈니스 로직 담당"
@RestController = "이 클래스가 API 요청 받는 입구"라는 표시
@RequestMapping("/api/posts") = 이 클래스의 모든 API 기본 주소 (/api/posts)
@PostMapping/@GetMapping = 각각 POST/GET 요청 받을 때 실행


@RequestBody = 클라이언트가 보낸 요청 데이터(JSON)를 자바 객체로 자동 변환해주는 표시입니다.

GenerationType.IDENTITY는 번호(id) 채우는 방식 지정
@GeneratedValue(strategy = GenerationType.IDENTITY )
번호를 자동으로 1,2,3 채움


@ManyToOne의 정의: JPA에서 두 엔티티 간 "N:1 관계"를 나타내는 어노테이션입니다.
그 이상도 이하도 아닙니다 — 특정 도메인 의미는 없고,
순수하게 관계의 형태(다대일)만 나타냅니다.


관계를 맺는 필드마다 매번 표기해야 합니다.

Entity 간 연관관계는 4종류 중 하나를 반드시 명시해야 합니다:

@OneToOne (1:1)
@OneToMany (1:N)
@ManyToOne (N:1)
@ManyToMany (M:N)

순수 관계 표시입니다.
